# Gita for Me

A calm, mobile-friendly Bhagavad Gita reflection site. Reflections are curated and matched locally in your browser. AI-generated guidance is not connected, and the text you enter is not sent to an AI service. Payments and subscriptions are not implemented.

## Deploy on Vercel

Import this repository as a static site. Use the root directory, with no build command and no framework preset. Add `gitaforme.me` under Project Settings → Domains and use the DNS records Vercel provides for this project. The `CNAME` file records the requested custom domain.
